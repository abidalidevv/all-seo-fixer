All-in-One SEO Fixer & Auditor — User & Developer Manual

Complete, production-ready documentation for WordPress site owners, SEO managers, and developers.

🚀 Overview & Purpose

All-in-One SEO Fixer & Auditor is a comprehensive, professional-grade WordPress SEO diagnostic, speed optimization, and security plugin. Built specifically to eliminate expensive monthly subscription paywalls, it provides 100% free access to enterprise SEO diagnostics under the open-source GPL-2.0 license.

It combines 360° site audits, real-time 404 URL monitoring, Google Indexing API v3 direct submissions, Google Search Console keyword rank tracking, PageSpeed Insights v5 integration, Page Builder bloat reduction, and 1-click automatic fixers into a unified WordPress Admin Native interface.

📥 Installation & API Setup Guide

1. Plugin Activation

Upload or clone the plugin repository into your WordPress installation directory:

wp-content/plugins/all-seo-fixer/

Activate the plugin via WordPress Admin → Plugins → Installed Plugins.

2. Google PageSpeed Insights API Key

  1. Visit the Google Cloud Console Credentials Page.
  2. Create an API Key and restrict it to "PageSpeed Insights API".
  3. Paste the API key in All SEO Fixer → Settings.

3. Google Search Console Service Account JSON Key

  1. Open Google Cloud Console and create a project.
  2. Enable both "Indexing API" and "Web Search Inspection API".
  3. Go to IAM & Admin → Service Accounts → Create a Service Account with Owner role.
  4. Keys tab → Add Key → Create New Key (JSON) and download the JSON file.
  5. In Google Search Console → Settings → Users & Permissions, add the Service Account email address as an Owner.
  6. Paste the entire JSON key text in All SEO Fixer → Settings.

⚙️ User Manual & Module Guide

360° Audit Dashboard

Click Run Full 360° SEO Audit to scan published pages. The engine generates a clean Live SEO Health Status table and an Action Plan & Recommended Fixes list with 1-click resolution buttons.

Google Indexing & Live Rank Tracker

Use the Instant Indexing input to push newly published or updated URLs directly to Google's indexing queue. Use Fetch Live Keyword Ranks to inspect search terms, impressions, and average rank positions.

PageSpeed Insights & Core Web Vitals

Test any published page URL for Mobile or Desktop strategies. Displays 0–100 category scores and exact Core Web Vitals timings (LCP in seconds, TBT in milliseconds, CLS score).

301 Redirect Manager & 404 Monitor

Manage permanent 301 redirects without editing server .htaccess files. The Real-Time 404 Monitor displays logged missing URLs; click ⚡ Create 301 Redirect to pre-fill redirect rules instantly.

Security & Sanitization Protocols

  • Capability Check: Every AJAX action executes asf_cap_check() checking manage_options.
  • CSRF Nonce Check: Every request executes asf_check_nonce() validating asf_admin_nonce.
  • SQL Security: Custom queries use $wpdb->prepare() with strict type placeholders (`%s`, `%d`).
  • Batched DB Execution: Deletions run in 50-item loops via core wp_delete_post() APIs to respect PHP memory limits.
